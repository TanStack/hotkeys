scope.createHotkeySequences

Register many multi-key sequences in one hook (like Vim commands). Keys must be pressed within the timeout window (default: 1000ms).

Vim-Style Commands

Sequence Action
g g Go to top
G (Shift+G) Go to bottom
d d Delete line
y y Yank (copy) line
d w Delete word
c i w Change inner word

Input handling

Sequences are not detected when typing in text inputs, textareas, selects, or contenteditable elements. Button-type inputs ( type="button", submit, reset) still receive sequences. Focus the input below and try gg or h e l l o — nothing will trigger. Click outside to try again.

Chained Shift+letter sequences

Each step is a chord: hold Shift and press a letter. You can press Shift alone between steps—those modifier-only presses do not reset progress, so the next chord still counts.

Sequence Action
Shift+r then Shift+ t Chained Shift+letter (2 steps)
