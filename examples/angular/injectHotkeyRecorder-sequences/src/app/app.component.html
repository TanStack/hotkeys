Recording Sequences

injectHotkeyRecorder with maxSteps records up to that many chords. Click Edit, press each chord in order, then press Enter (or reach four chords) to save. One chord saves as a regular hotkey. Escape cancels; Backspace removes the last chord or clears when empty.

Usage

import {{
          '{'
        }} injectHotkeys, injectHotkeyRecorder, injectHotkeyRegistrations {{
          '}'
        }} from '@tanstack/angular-hotkeys'

// Record a chord or a sequence of up to four chords
const recorder = injectHotkeyRecorder({{ '{' }}
  maxSteps: 4,
  onRecord: (hotkey) => save(hotkey), // 'Mod+S' or ['G', 'G']
{{ '}' }})

// Register chords and sequences together, with meta
injectHotkeys(() =>
  this.shortcuts().map((s) => ({{ '{' }}
    hotkey: s.hotkey,
    callback: () => handleAction(s.id),
    options: {{ '{' }}
      meta: {{ '{' }} name: s.name, description: s.description {{ '}' }},
    {{ '}' }},
  {{ '}' }})),
)

// Read all registrations reactively
const registrations = injectHotkeyRegistrations()
// registrations()[0].options.meta?.name → 'Save'
// registrations()[0].triggerCount → 3
